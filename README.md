# 视频 / 音频分割脚本

选择音频或视频文件，按指定起止时间、固定时长或随机时长范围切分。默认根据实际轨道识别类型，音频片段沿用原素材的格式，视频片段保存为 MP4。带专辑封面的音频也会识别为音频。支持中文路径和带空格路径。

## 准备环境（Windows）

需要 Python 3.9 或更新版本，以及包含 ffmpeg、ffprobe 和所需输出编码器的 FFmpeg。无需安装 Python 第三方库。

如果电脑有 winget，可以在 PowerShell 中安装：

```powershell
winget install --id Python.Python.3.12 -e
winget install --id Gyan.FFmpeg -e
```

安装后重新打开终端，确认以下命令可运行：

```powershell
python --version
ffmpeg -version
ffprobe -version
```

## 使用方法

Windows 下双击 `startSplitVideo.bat`，会自动启动本地服务并在浏览器中打开中文操作页面。启动器固定使用项目内的 `.venv\Scripts\python.exe`。请确保该虚拟环境已创建，且 FFmpeg 已加入 PATH。

在页面上选择本地文件或粘贴完整路径。切分录音或音乐时，保留「自动识别」，在「音频输出格式」中选择格式，设置片段时长后点击「开始切分」。从视频提取声音时，先选择「切分音频」，再选输出格式。右侧显示进度，完成后可打开结果文件夹。同一服务一次处理一个任务，刷新页面可以查看当前进度。重启服务后仍可在磁盘查看输出文件。

「跟随原素材」是默认选项。WAV 录音切成相同 PCM 编码的 WAV，MP3 切成 MP3，其他音频按原容器和编码导出。从视频提取时沿用音轨编码，例如 AAC 音轨保存为 M4A。可手动选择 MP3、WAV（24 位 PCM）、FLAC、M4A（AAC）或 OGG（Vorbis）。如果本机 FFmpeg 无法写出原格式，请选择另一种输出格式。

已有时间表时，在「设置切分方式」中选择「自定义时间段」。每行填写原素材上的开始和结束秒数，也可以直接粘贴带表头、时长列的表格。页面自动预览每段时长和合计时长。「填入 10 段示例」可载入覆盖 0–204 秒的时间表，再逐行调整。

```text
截取位置(单位:秒)    时长
0-22               22秒
22-40              18秒
40-58              18秒
```

起止时间支持小数，时长列可省略。每行独立生成一个文件，按填写顺序编号，允许跳过区间或重复截取。最后一行之后的内容会跳过。填写的时长与起止时间不符，或区间超出所选轨道的可用范围时，会在导出前提示。

处理期间保持启动窗口打开；完成后可以按 Ctrl+C 关闭服务。页面仅监听本机地址，文件不上传到外部服务。默认使用空闲端口，不需要安装 Node.js 或额外 Python 包。网页入口为 `web_app.py`，前端为 `web/index.html`，不要直接双击 HTML 文件。

在本目录打开终端，进入交互模式后按提示输入路径、输出类型和时长：

```powershell
python .\split_media.py
```

下面的命令把 WAV 录音按每段 60 秒切成 WAV 文件。

```powershell
python .\split_media.py "D:\音频\会议录音.wav" --duration 60
```

要在命令行使用同一份时间表，将它保存为 UTF-8 文本文件，再运行

```powershell
python .\split_media.py "D:\音频\会议录音.wav" --segments-file ".\时间表.txt"
```

每段视频在 30～60 秒之间随机分配：

```powershell
python .\split_media.py "D:\视频\示例.mp4" --min 30 --max 60
```

固定每段 60 秒（末段保留剩余内容，可以短于 60 秒）：

```powershell
python .\split_media.py "D:\视频\示例.mp4" --duration 60
```

通过 `--audio-format` 指定音频格式，支持 `source`（默认）、`mp3`、`wav`、`flac`、`m4a` 和 `ogg`。下面的命令从视频中提取音轨，切分后保存为 WAV 文件。

```powershell
python .\split_media.py "D:\视频\示例.mp4" --mode audio --audio-format wav --min 30 --max 60 --output "D:\切分结果"
```

所有时长单位为秒，支持小数。范围模式会同时考虑总时长和剩余片段，避免末段过短。如果无法满足范围（例如 65 秒无法完整分成 40～60 秒的片段），会报错；请调整范围或使用固定时长模式。相同范围每次切分的段数及长度可能不同；上下限相同时只适用于总时长能整除的情况。

## 保存结果

默认保存到项目根目录下的 `data`（本项目为 `D:\code\SplitVideo\data`），不受源文件位置或启动目录影响。每次切分都创建独立文件夹，页面填写保存目录或命令行指定 `--output` 可覆盖默认位置。例如：

```text
data/
  示例_video_20261117_120000_123456/
    0001.mp4
    0002.mp4
    segments.json
```

`segments.json` 记录原文件、每段的起止时间、计划时长和完成状态。失败或中止后保留已完成片段；未完成文件带 `.partial` 标记。重新运行会创建新文件夹，不覆盖旧结果，也不会自动续传。

视频使用 H.264/AAC 重新编码，以便从指定位置切分，耗时取决于视频长度和电脑性能。只保留第一条视频轨和第一条音轨，不保留字幕及其他轨道。音频任务在 `segments.json` 的 `audio_format` 字段记录所选格式。由于视频帧、音频采样和编码填充的限制，输出文件实际时长可能与计划时长有少量差异；切分不会识别语句或场景边界。

点击「重置，开始新任务」可清空源文件路径、保存目录、进度、结果列表和错误提示，并恢复默认参数（自动识别、音频格式跟随原素材、随机 30～60 秒）。已保存文件不会删除。运行中的任务不能重置；完成或失败后可重置并再次切分。
